# KeY Headless CLI (`key.cli`) — Implementation Plan

Date: 2026-11-14
Branch: `weigl/key-cli` (from `origin/main` = `624adc3699`)
Spec: `docs/superpowers/specs/2026-11-14-key-cli-interface-spec.md` (v2, authoritative)

## Overview

Build a standalone headless CLI module `key.cli` implementing spec §1–§10 exactly, as
subcommands `key-cli prove|list|replay|script`. `key.ui`'s `Main` stays untouched
(user-approved deviation from spec §0: the legacy `java -jar key.jar --auto` invocation
keeps today's behavior and does *not* gain the new contract; acceptance scripts target
`key-cli.jar` instead). The shadow jar is named `key-cli.jar`, main class
`org.key_project.key.cli.Main`.

### Locked decisions (do not revisit)
- Subcommand shape (not flat flags): `prove <files...> [opts]`, `list <files...> [opts]`,
  `replay <PROOF> [--contract NAME]`, `script <load-file> <script-file> [opts]`.
- Worst-status exit-code order: `error(3/4) > timed_out(2) > open(1) > closed(0)` (§1).
- stdout order: all human/protocol output first (`OPEN-GOAL-COUNT`, `SCRIPT …`, listing);
  `KEY_RESULT` lines are always the last N lines (§2).
- `--proof <PATH>` valid only for single-contract runs; multi-contract requires
  `--proof-dir <DIR>` (files named `<contract-index>.proof`), else `KEY_ERROR`, exit 3 (§3).
- `KEY_RESULT` JSON is produced by a small hand-rolled serializer (byte-exact, no new dep).
- `--config-dir <DIR>` sets `System.setProperty(PathConfig.KEY_HOME_PROPERTY, <DIR>)`
  (`"key.home"`) as the very first thing in `Main`, before any KeY class is touched.
- Contract canonical NAME = `Contract.getName()` (verified: it *is*
  `ContractFactory.generateContractName(baseName, kjt, pm, specifiedIn, id)`, exactly the
  §4.1 grammar). Listing `<FQCC>::<METHOD>` = `contract.getTarget().name()` (byte-compatible
  with the legacy "Method:" line). Listing order: stable sort by canonical NAME.
- Default selection in `prove`: `--choose-contract` (repeatable) → load-file
  `\chooseContract`/`\proofObligation` → **all** contracts. `key.cli` never reads stdin
  implicitly (the legacy stdin-index flow belongs to the untouched `key.ui` jar); a bare
  integer passed to `--choose-contract` covers spec A1's `--choose-contract 0`.
- `--choose-contract` accepts a NAME **or** a bare decimal `<IDX>`;
  `NAME.#<IDX>` selects the IDX-th entry among identical NAMEs (§4.4).

### Grounded API facts (verified against tree at `624adc3699`)
- Driver: `de.uka.ilkd.key.util.ProofStarter` (key.core): `init(Proof)` (inherits settings &
  timeout from the proof), `setTimeout(long)`, `setStrategyProperties(StrategyProperties)`,
  `start()` → `org.key_project.prover.engine.ProofSearchInformation<Proof,Goal>` with
  `reason()`, `getTime()`, `getProof()`, `isError()`, `getException()`,
  `getNumberOfClosedGoals()`. Timeout stop reports a reason mentioning timeout — detect via
  `reason()` plus `strategySettings.getTimeout() > 0 && elapsed >= timeout` fallback.
- Loading: `KeYEnvironment.load(Path)` (key.core `control`) → `getInitConfig()`,
  `getServices().getSpecificationRepository().getAllContracts()` (ImmutableSet<Contract>),
  `getLoadedProof()`, `getReplayResult()`, `close()`. Listing filters
  `KeYTypeUtil.isLibraryClass(c.getKJT())` like `ConsoleProofObligationSelector`.
- Contract: `createProofObl(InitConfig)` → `ContractPO` (a `ProofOblInput`).
- Proof saving is plain UTF-8 text (`OutputStreamProofSaver.save(Path, OutputStream)` +
  `ProofSaver.saveToFile(Path, Proof)`); marker line has to be prepended (see Phase 5).
- Proof parsing: `ParsingFacade.parseFile(Path|URL)` + `JavaKeYLexer` via
  `CharStreams.fromPath`. A leading `KEY_PROOF_STATUS …` line must be skipped.
- `\settings` already parsed: `KeyAst.File.findProofSettings()` → `ProofSettings`
  (with `\chooseContract`/`\proofObligation` in `ProblemInformation`).
  `AbstractProblemLoader.loadByChosenContract(name)` → `SpecificationRepository.getContractByName`
  → `contract.createProofObl(initConfig)` (verify acceptance; may be directly reusable).
- Replay: `KeYEnvironment.load(proofPath)` replays stored steps via
  `IntermediateProofReplayer`; `ReplayResult` carries status/errors.
- Scripts: `de.uka.ilkd.key.scripts.ProofScriptEngine` + SPI
  `ProofScriptCommand` (`auto`, `rule`, … available); §7.1 grammar is a new thin interpreter
  over this + `ApplyStrategy` (`proceed` ≈ one `auto` step, `print-open-goals` new).
- SMT counters: `proof.getStatistics().smtSolverApps` ⇒ `smtCalls`; `smtProved` = closed goals
  closed by `SMTRuleApp` (count via tree walk; both 0 when SMT disabled).
- `--config-dir`: `PathConfig.KEY_HOME_PROPERTY = "key.home"` read in static block.

### Task 5.4: `replay <PROOF>` (§7.2)
Files: `key.cli/src/main/java/org/key_project/key/cli/replay/ReplayCommand.java`

Interfaces:
- `replay <PROOF> [--contract NAME] [--config-dir DIR]`: load the proof via
  `KeYEnvironment.load` (marker-tolerant). If the file’s marker says closed → expect the
  internal replay to agree; both closed → print `REPLAY closed 0`, exit 0. Marker `open <n>`
  → print `REPLAY unclosed <n>`, exit 1 (G2 even when internal replay disagrees, per marker
  rule: marker wins for header-carrying files). No marker → `proof.closed()` decides
  (`REPLAY closed 0` / `REPLAY unclosed <n>`). Replay/loader errors or marker-vs-internal
  disagreement → `REPLAY incompatible <reason>`, exit 3.
- `--contract NAME` filters the loaded proof’s obligation, matching §4.2.

TDD:
- G1: closed proof → `REPLAY closed 0`, exit 0.
- G2: same file with header swapped to `KEY_PROOF_STATUS open 3` → `REPLAY unclosed 3`, exit 1.
- Corrupt/foreign proof → `REPLAY incompatible …`, exit 3.
- Marker says closed but replay errors → `REPLAY incompatible …`.

### Phase 6 — Open-goal inspection (§6) + scripted proving (§7.1)

### Task 6.1: `--print-open-goals [MAX]` (§6)
Files: `key.cli/src/main/java/org/key_project/key/cli/OpenGoalPrinter.java`, `ProveCommand`

Interfaces:
- After proof search, print to stdout:
  `OPEN-GOAL-COUNT <N>` then up to MAX `GOAL <id> <position-path>` blocks
  (`MAX` default 10, `0` = unlimited; picocli `arity = "0..1"`, `fallbackValue = "10"`;
  count always true).
- Block: two-space-indented antecedent terms, `==>` line, succedent terms, blank line —
  exactly per §6 (compare to spec layout; each formula on its own line via LogicPrinter,
  `--no-truncate-formulas` disables truncation).
- `<position-path>` = dot-separated ints from the proof root to the goal node, matching
  `^[1-9][0-9.]*$` and usable by `at` (§7.1). Compute from `goal.node()` child-index walk
  (spike to confirm the exact per-node index API: `Node` parent/child indexing).

TDD:
- F1: two runs on the same open contract → byte-identical blocks.
- F2: on an open contract, printed formulas non-empty, every position-path matches the regex.
- MAX truncation: `--print-open-goals 1` on a ≥2-goal contract prints 1 block but true count.
- Determinism also holds with `--no-truncate-formulas`.

### Task 6.2: Script interpreter (`script` subcommand, §7.1)
Files: `key.cli/src/main/java/org/key_project/key/cli/script/ScriptCommand.java`,
`ScriptInterpreter.java`

Interfaces:
- Grammar (line-oriented, `#` comments):
  `proceed | apply <rule-name> [at <position-path>] [for <term>] | auto [<limit>] |
  assert-closed | print-open-goals`.
- `ScriptInterpreter` parses lines, executes against the selected obligation: `proceed`/`auto`
  drive `ApplyStrategy` (limit-capped); `apply` resolves rule by name at position (use
  existing `RuleCommand`/`ProofScriptEngine` facilities; `at` selects the goal from the last
  `GOAL` in the previous `print-open-goals`); `assert-closed` final check.
- Per line stdout: `SCRIPT OK <line>` / `SCRIPT FAIL <line> <reason>`; end:
  `SCRIPT FINAL closed` (exit 0) / `SCRIPT FINAL open <n>` (exit 1). No `assert-closed` →
  outcome from the §2 record.
- Options: `--choose-contract`, `--timeout`, `--config-dir`.

TDD:
- G3: hand script with ≥2 distinct commands incl. `apply` on the known-open `size()`-style
  obligation → `SCRIPT OK` on every line and `openGoals` strictly drops between first and
  last `print-open-goals`.
- Comment lines ignored; unknown command → `SCRIPT FAIL <line> Unknown command …`.
- `assert-closed` on closed proof → `SCRIPT FINAL closed`, exit 0.
- `auto 5` consumes ≤ 5 strategy steps (spike: measure via applied rule count or a tiny proof).
